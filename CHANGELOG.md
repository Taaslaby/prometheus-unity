# Changelog

## [0.3.0] — 2026-09-02

### ЗЕВС — архитектор над Прометеем

Прометей выращивает (морфогены, градиенты, прореживание); Зевс
ПРОЖИГАЕТ АРХИТЕКТУРУ: декларирует ПРОВОДКИ — монтажные схемы с
параметрами-портами — и разворачивает их в Layout. Архитектор думает
проводками, не морфогенами:

```csharp
var layout = Zeus.Sensorimotor()
    .And(Zeus.Gate("SL", "SR", into: "ML"))
    .And(Zeus.Fan("SR", "MR", "TAIL"))
    .And(Zeus.Converge("TAIL", "ML", "MR"))
    .Build();   // растёт Прометеем как обычно
```

Слои: Blocks — микросхемы (низкий уровень); Zeus — ПРОВОДКИ (монтаж
микросхем, стыковка к чужим регионам, коллизии портов); Layout/рост —
Прометей.

### Библиотека проводок первой очереди
- **Gate(a, b, into)** — «проводка ГАМК-затвора», с которой Зевс
  начался: путь a∩b → into (CoincidenceGate + порт-клейм).
- **Compare(pred, fact, ack, err)** — прогноз vs факт: ack/err-исходы.
- **Differential(leftS, rightS, leftM, rightM)** — сенсорная симметрия
  → моторная асимметрия: прямые пути свои-к-своим, кросс через
  инвертор (антагонистическая пара), Exclude кросс-прямых.
- **Fan(sense, targets...)** — веер: один сенсор в N целей.
- **Converge(motor, sources...)** — сход: N источников в один пул.
- **Cpg(drive, leftOut, rightOut)** — half-center-качалка; выходные
  ПОРТЫ L_OUT/R_OUT объявляет Зевс (блок строит только внутренность).

### ZeusWiring: доменная сборка
- ClaimPort: детект коллизий — два гейта на один выход = внятный
  InvalidOperationException, не каша из рёбер.
- Порты и авто-имёна регионов: детерминированный FNV-хэш тегов
  (PortId) — один монтаж = один id.

### Тесты: +6 (56 xunit): прожиг гейта с ростом, коллизия
портов, антагонизм дифф-пути (SR→ML исключён, инвертор жив),
веер+сход, CPG-структура (порты объявлены), архитектурная
читаемость сборки. EditMode диомы зелёный, харнесс 4/4.

## [0.2.2] — 2026-09-02

### Блок-Билдер: затвор работает в выращенном мозге (BlockBrain PASS)

Первая схема, собранная из блоков и выращенная Прометеем, показала
ЖИВОЙ ГАМК-затвор: два входа вместе открывают мотор сильнее суммы
поодиночке (ОБА=1013 спайков > SL+SR=773). Схема: Core + CoincidenceGate
(SL∩SR→ML) + Comparator (ERR-путь удивления жив).

### Четыре правила стыковки блоков (все — от падений BlockBrain)
1. **Реле секретируют + HostWire**: вход = аксон ИСТОЧНИКА к приманке
   реле; растёт владелец аксона (`AxonTo("SL","G1.A",len)`). Первая
   версия росла наоборот — реле к источнику: SL→G1.A = 0 рёбер.
2. **Exclude прямого пути**: гейт подменяет вход→выход, иначе вход
   пробивает мотор мимо логики (SL→ML прямо 56 рёбер, одиночный SL
   открывал всё). `Exclude(from,to)` в LayoutBuilder.
3. **Носитель сигнала ≠ дизингибция**: снятие тормоза открывает
   ПУТЬ, но не даёт плюс — реле A/B обязаны сами нести возбуждение
   на выход (Axon(output)); GATE-тормоз давит его до совпадения.
4. **Геометрия решает**: морфогены Core заглушают далёкую приманку,
   реле прижаты к источникам, аксон длиннее дистанции (SR→ML ≈135
   при len 110 не дорастал; 200 — дорос).

### API: LayoutBuilder.AxonTo(tag, morphogen, len) — стыковка
входных портов из сборки; Blocks: реле A/B — приманки+носители.

## [0.2.1] — 2026-09-02

### Прометей-Билдер: библиотека блоков-мотивов

`Runtime/Core/Grow/Blocks.cs` — схемы собираются не по нейрону, а из
микросхем: каждый блок — проверенная конфигурация с внутренней
проводкой, Growing-аксонами и портами. Композиция флюентная:
`.And(Blocks.CoincidenceGate("G1", "SL", "SR", "ML"))`.

- **CoincidenceGate** — ГАМК-затвор: два входа сходятся на
  дизингибиторе, тот снимает тоническое торможение выхода. Логическое
  И спайковым образом (дизингибция, как таламический relay).
- **Comparator** — предсказание vs факт: совпадение гасит ERR-затвор
  и открывает ACK. Схема-«удивление» для PatternBox/HC.
- **HalfCenter** — взаимно тормозная пара: основа CPG.
- **ReflexArc** — классическая дуга S→I→M.
- **Core()** — холст рыбки из блоков (пары = Layouts.Fish).

Два правила морфоген-стыковки выучены тестами и записаны в код:
внутренние цели блока секретируют свой тег; региона-цель Core тоже
(иначе Axon не найдёт приманку). Рост идёт только по Axon — Allow
один даёт разрешение без проводки (DIS→ACK не рос, пока не добавили
аксон).

### Тесты: +6 (50 xunit): сборка/оба-входа/осциллятор/компаратор/
композиция без коллизий тегов/Core≡Fish-пары.

## 0.2.0 — UPM-пакет: аквариум растит мозги через Прометей

### BREAKING: раскладка пакета

`Core/` + `Unity/` + `tools/` стали `Runtime/` + `Tests/` + `Dev~`.
Логика не менялась ни на строку — двигались файлы, чтобы пакет можно
было подключить в проект как `file:../../prometheus-unity`:

| было | стало | почему |
|---|---|---|
| `Core/Prometheus.Runtime/` | `Runtime/Core/` | то, что импортирует Unity |
| `Unity/Runtime/` | `Runtime/Unity/` | то же |
| `Core/Prometheus.Tests/` | `Dev~/Prometheus.Tests/` | xunit без asmdef ломал импорт |
| `tools/golden/` | `Tests/Editor/Data/` | golden виден и xunit-у, и редактору |
| `tools/{bench,check,golden-probe}` | `Dev~/{bench,check,golden-probe}` | bin/obj не должны попасть в импорт |
| `Core/Prometheus.Runtime/*.csproj` | `Dev~/Prometheus.Runtime/` | компилирует `Runtime/Core/**/*.cs` |

`scripts/verify.sh` появился: `tests | check | bench` — как у dioma-engine.

### Починки, всплывшие при первом реальном импорте

- **ComputeDiffusionBackend**: `Grid` конфликтовал с `UnityEngine.Grid`
  (CS0104 на каждой подписи) — using-псевдоним.
- **DiffusionJob**: `FloatPrecision.Strict` не существует в Burst
  (только `High`) — CS0117. И главное: `[WriteOnly]`-массив в
  `IJobParallelFor` разрешает запись только в элемент job-index, наш
  `idx` декодированный — safety роняла джобу `IndexOutOfRange`, и
  центр ячейки 50 не распахивался по соседям. `NativeDisableParallelForRestriction`.
- **GoldenUnity**: `System.Text.Json` в Unity нет; байтовый паритет
  остался xunit-набору, редакторная сторона теперь проверяет своё —
  Burst против CPU (ловит обе починки выше) и главный инвариант
  игрового пути: нарезка `RunSlice(k)` == `Grow` при любом k.
- `PrometheusBridge.GoldenPath` (путь от `dataPath` в чужой проект)
  → `PrometheusPaths.GoldenDir` через `PackageInfo.FindForPackageName`.

### Игровой путь (используется аквариумом dioma-unity)

`Brain.Begin(layout, seed, steering)` → `RunSlice` под бюджет времени
кадра → `Complete()` → `ToDiomaJson(DiomaBrainSpec.Fish())` →
`DiomaBrain.FromJson`. Наследование: `Steering.MutatedFrom(seed, sigma)`
— ген роста мутирует, регионы и их размеры не меняются, инстинкты
Болдуина (индексы нейронов) наследуются корректно.

Замер жизнеспособности мутаций (64 сида, сигма 0.08): дефолтный ген —
64/64 живых входов в TAIL, мутации — ~80%; глухой TAIL — эволюционно
отбраковываемая линия, не баг.
